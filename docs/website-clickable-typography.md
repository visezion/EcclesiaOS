# Clickable heading and text widgets

In Website Studio's section builder, add or edit a **Heading** or **Text** widget. Check **Make heading clickable** or **Make text clickable** to reveal the **Link URL** field. Enter a full `https://` URL, a site path beginning with `/`, a `#section` anchor, or a `mailto:` address, then save the section. Uncheck the option to render ordinary text while keeping the saved URL for later.

Links retain the widget's typography and have a visible underline and keyboard focus indicator. Unsupported URL schemes, including `javascript:`, are discarded when the section is saved. The setting works in both regular and nested sections.

**Card** widgets also have a **Make entire card clickable** checkbox. The existing **Card / button link** URL applies to the whole card when checked. When unchecked, a visible card button can still link to that URL. Older cards with a link remain fully clickable until you turn this checkbox off.
